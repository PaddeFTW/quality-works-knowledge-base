## 1. Vid personolycka

### Akut
1. Ring 112. Håll dig lugn. SOS ALARM ställer frågor om vad som hänt, var ni är, antal skadade, medvetande, tidigare sjukdom, mediciner, personuppgifter.
2. Följ alla instruktioner (t.ex. stabilisera huvud, stoppa blödning).
3. Starta HLR vid behov, använd hjärtstartare om tillgängligt.
4. Möt upp ambulans/räddningstjänst/polis om möjligt (lämna aldrig allvarligt skadad ensam).
5. Kontakta anhöriga.
6. Erbjud krissamtal till inblandade och övrig personal.
7. Kontakta berörd myndighet vid behov (Arbetsmiljöverket, Försäkringskassan).
8. Följ upp det inträffade.

### Icke-akut
1. Uppsök akutmottagning, vårdcentral eller ring 114 14.
2. Mindre skärsår → första hjälpen-låda.
3. Kontakta anhöriga vid behov.
4. Erbjud krissamtal.
5. Kontakta myndighet vid behov.
6. Följ upp.

---

## 2. Vid brand

### Akut
1. Ring 112. Svara på frågor om vad som brinner, om någon är kvar (även djur), explosionsrisk, antal skadade m.m.
2. All personal utrymmer och samlas på återsamlingsplats. Utsedd ansvarig räknar in personalen.
3. Följ instruktioner från SOS ALARM.

### Icke-akut / mindre brand
1. Släck själv med brandsläckare eller brandfilt **utan att utsätta dig eller andra för fara**.
2. Mindre brännskada → akutmottagning/vårdcentral eller 114 14.
3. Kontakta anhöriga, erbjud krissamtal, kontakta myndighet vid behov, följ upp.

---

## 3. Vid miljöolycka

1. Kontrollera att ingen är skadad (om ja → se personolycka).
2. Kontrollera att det inte brinner och om det finns explosiva ämnen i närheten (om ja → se brand).
3. Begränsa skadan på plats **utan att utsätta personal för risker**.
4. Påbörja sanering (utbildad personal).
5. Kontakta berörda myndigheter (t.ex. miljönämnden i kommunen).
6. Följ upp.

**Ytterligare stöd från källan:**  
Vid eventuell miljöolycka finns nödlägesberedskap i fordon. Följ dokumenterad instruktion “Checklista nödlägesberedskap”.
