# Vem kan svara i ISO Quiz

Hela fältunderlaget per fråga: `Fragobank_v2/templates/fragobank/21_Information_och_Bevis.md`. Inget nytt ISO-krav.

## Verkligheten i 1–50 anställda

I 1–5 kan VD *börja* nästan alla svar. Det är inte samma sak som att VD har bevisen. I 6–20 sitter vardagen hos arbetsledare, administratör och den som gör jobbet.

Revisor frågar tre saker som redan finns i metoden: gör ni det, kan ni visa det, gör ni så varje gång.

## VD kan svara direkt

A1 verksamhet, A2 omvärld, A3 vem som ställer krav, B1–B4 löften, B5 vem som gör vad, C6 enkla mål, F6 årligt ledningsmöte.

E1 (hur en order tas emot) hör hit i 1–5. När någon annan säljer: Säljare / kundansvarig.

VD kan säga *att* något finns. Papperet ligger ofta hos administratören.

## Kräver andra

Allt övrigt i A–G. Särskilt: C3 och E5 och B6 → Skyddsombud + Platschef / arbetsledare. A4, C4, D6, E6 → IT-ansvarig eller IT-leverantör / Administratör. D1–D3 → Platschef / arbetsledare + Administratör. E2 och E4 → Den som gör jobbet. F1 → Säljare / kundansvarig. F5 → den som utsetts, sällan VD ensam. D5 → Administratör.

## Roller i fältet information_finns_hos

VD / ägare · Platschef / arbetsledare · Administratör · Ekonomi / lön · Säljare / kundansvarig · Projektledare · Skyddsombud · Den som gör jobbet · IT-ansvarig eller IT-leverantör · Inköpsansvarig · HR (ofta samma som administratör eller VD)

## Var det ligger

Inte i ett “ledningssystem”. Huvudet, hemsidan och offerter, mejl, personalpärm / avtalsmapp, gemensam digital mapp, affärssystem / lön / kundlista, checklistor i bilen, avfallskärl / kemikaliehylla / SDB-pärm, kalendern för årsmötet.

## Bevis som redan finns i banken

Nästan alltid: underskrivet löfte, lista med namn och ansvar, kort risk- eller farolista, introduktionschecklista, offert / avtal / arbetsorder, reklamation eller tillbud, protokoll från årligt ledningsmöte.

Miljö valt: kemikalielista och säkerhetsdatablad, avfallsavtal, lista över det som påverkar miljön.  
Arbetsmiljö valt: riskbedömning, skyddsrondprotokoll, tillbud, nödplan.  
Information valt: lista över uppgifter och system, användarregister, backup-rutin, incidentanteckning, lista över valda skyddsåtgärder.
