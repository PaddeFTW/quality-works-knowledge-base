# Enkla termer (bygg, under 50 anställda)

Säg **krav** och **avsnitt**. Inte klausul.

| Ord | Betyder hos oss |
|-----|-----------------|
| Ledningssystem | Så vi styr jobb från anbud till överlämning, så att kvalitet och miljö blir lika på varje plats. |
| Kontext | Vad som påverkar oss: kunder, kommun, väder, personal, priser, klimatkrav. |
| Intressent | Den som ställer krav: beställare, kommun, personal, UE, grannar, försäkringsbolag. |
| Omfattning | Vad systemet gäller: t.ex. nybyggnad och ROT i Skåne, inte egen fabrik. |
| Process | En kedja: anbud → avtal → startmöte → utförande → egenkontroll → överlämning. |
| Risk | Något som kan gå fel: fuktskada, fel material, dålig UE, tidsbrist. |
| Möjlighet | Något vi kan vinna på: ramavtal, återbruk, färre reklamationer. |
| Kvalitetskultur | Att folk vågar säga till och inte signerar egenkontroll som inte är gjord. |
| Etik | Ärliga mätetal, inga dolda ÄTA, rätt bilder till beställaren. |
| Förändring | Nytt arbetssätt, ny UE, nytt material, ny platschef – planeras innan det slår. |
| Miljöaspekt | Det vi gör som påverkar miljön: massor, spill, transporter, el, kemikalier. |
| Bindande krav | Lagar, föreskrifter och krav i kontrakt som vi måste följa. |
| Egenkontroll | Kolla jobbet mot ritning och checklista innan nästa steg. |
| Avvikelse | Fel, tillbud, felsortering, reklamation – tas om hand med orsak och åtgärd. |
| Bevis | Det revisorn kan se: protokoll, foto, vågsedel, SDB, avtal, kvittens. |
| UE | Underentreprenör. Samma regler på vår plats. |

Använd företagets egna ord i ordlistan (fråga 3 i 38-startfrågorna).
