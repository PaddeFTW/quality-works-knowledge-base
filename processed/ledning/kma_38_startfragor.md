# KMA 38 Startfrågor – Praktisk guide för att komma igång med ledningssystem

**Källa:** Bilaga 3 – 38 Frågor.csv + Bilaga3_38_Fragor_Mapping.txt  
**Datum:** 2026-07-12  
**Syfte:** Enkel och strukturerad startpunkt för att bygga ett KMA-ledningssystem (Kvalitet, Miljö, Arbetsmiljö).

Varje fråga har:
- En kort förklaring
- Exempel på svar (anpassat efter verksamhet)
- Koppling till ISO-avsnitt
- Koppling till UCP (Unified Control Point)

## Rekommenderad användning

- Använd frågorna som **interaktiv checklista** vid uppstart eller årlig genomgång.
- Koppla svaren direkt till UCP-tabellen för att skapa konkreta rutiner.
- Frågorna är perfekta som bas för en **onboarding-guide** eller **självskattning** i Quality WorX Apps.
