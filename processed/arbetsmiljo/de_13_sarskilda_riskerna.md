| Fält | Värde |
|------|-------|
| Förekommer | ☐ Ja ☐ Nej ☐ Osäkert |
| Moment | t.ex. tak, schaktkant, stomme, ställning |
| Ansvarig | |
| Deadline | |
| Status | {{atgard_status}} |

**Åtgärder att välja och konkretisera**

- Kollektivt skydd först: räcke, täckt öppning, skyddsnät, ställning med fotlist.
- Personligt fallskydd endast när kollektivt skydd inte räcker; förankringspunkt bedömd.
- Tillträdesled: trappa/hiss före stege.
- Håll avstånd till oskyddad kant. Märk och spärra.
- Inspektera skydd efter väder, lyft och skiftbyte.

Arbetsberedning krävs: ☐ Ja

## Risk 2 – Begravas under jordmassor eller sjunka i lös mark

| Fält | Värde |
|------|-------|
| Förekommer | ☐ Ja ☐ Nej ☐ Osäkert |
| Moment | t.ex. schakt, ledningsgrav, slänt |
| Ansvarig | |
| Deadline | |
| Status | {{atgard_status}} |

**Åtgärder**

- Utred mark, ledningar och grundvatten före start.
- Kompetent ledning av schakt när stöd eller släntkrav finns.
- Schaktstöd eller säker släntlutning. Inte vistas under osäkrad vägg.
- Massor och maskiner på säkert avstånd från kant.
- Daglig kontroll efter regn, vibration och natt.
- Utrymningsväg ur schakt.

Arbetsberedning krävs: ☐ Ja
