## Allmän information till den nyanställda

### Vid personolycka
1. Vid akut nödsituation – ring 112. Försök hålla dig lugn. Hjälp är redan på väg.
2. Kontakta närmaste chef/arbetsledare.
3. Kontakta skyddsombud.
4. Fyll i olycksfallsanmälan (blankett finns hos...).

### Vid brand
- Rädda dig själv och andra i fara.
- Larma 112.
- Försök släcka om det är säkert.
- Stäng dörrar och fönster.
- Gå till uppsamlingsplats: ____________________

### Anmäl olycksfall
Alla olycksfall och tillbud ska anmälas till närmaste chef som rapporterar till arbetsmiljösamordnare. Arbetsmiljösamordnare kallar skyddsombud.

## Allmänna ordnings- och skyddsregler

| Område | Regel |
|--------|-------|
| **Personlig skyddsutrustning** | Skyddsskor med stålhätta och spiktrampskydd skall användas. Övrig utrustning (t.ex. hjälm) används vid behov eller om arbetsplatsen kräver det. Arbetskläder med företagets logotyp används endast under arbetstid. |
| **Material** | Alla städar efter eget arbete. Personalutrymmen hålls rena och snygga. Material placeras på anvisade platser. Håll alltid transportvägar öppna. Ta hand om spillmaterial fortlöpande. |
| **Skyddsanordning** | Skyddsanordningar får ej monteras bort eller ändras utan skyddsombudets tillstånd. Spärra av eget arbetsområde vid behov. Återställ alltid skyddsanordningar som demonterats. (Underlåtenhet kan medföra straffpåföljd enligt AML 8 §2). |
| **Heta arbete** | Påbörja ej heta arbeten före tillstånd från Brandskyddsansvarig. Kontrollera att brandsläckare finns i omedelbar anslutning. Endast personal med godkänd utbildning i "Heta arbeten" får utföra sådana arbeten. |
| **Tillfällig el** | Ingrepp får endast utföras av behörig personal. Använd jordfelsbrytare. Skydda elkablar. |
| **Buller** | Maskiner med låg bullernivå skall om möjligt användas. Avskärma buller om möjligt. Använd hörselskydd. Hörselskydd med radio/MP3 får ej användas av säkerhetsskäl. |
| **Miljöfarliga ämnen** | Anmäl till arbetsledningen vid användning av farliga ämnen. Följ instruktioner. |
| **Maskiner** | Placera maskiner på anvisad plats då de ej används. För inhyrda maskiner som är besiktningsskyldiga skall maskinföraren visa intyg för ansvarig chef före användande. |
| **Förbandsmaterial** | Finns i personalutrymmen. |
| **Skador och tillbud** | Informera närmaste chef som omgående skall rapportera till arbetsmiljösamordnare. |
| **Larm** | Larmtelefonnummer: **112** |
| **Rökning** | Endast tillåtet utomhus för att ingen ska utsättas för passiv rökning. |
| **Alkohol och droger** | Under arbetstid är vi helt opåverkade av alkohol, narkotika och läkemedel (förutom egna receptbelagda). Vid behandling med varningsklassad medicin kan reaktionsförmågan nedsättas – beakta detta vid skärpt uppmärksamhet. |
| **Kränkande särbehandling** | Kränkande särbehandling accepteras inte. Med detta avses återkommande nedvärderande eller negativt präglade handlingar som riktas mot enskilda arbetstagare på ett kränkande sätt. |
| **Mobiltelefon** | Företagets mobiltelefon används endast under arbetstid och till arbetsrelaterade samtal. Privata samtal sker under raster med privat telefon. |
| **Konkurrerande verksamhet** | Anställd personal får inte bedriva konkurrerande verksamhet. Utnyttjande av företagets egendom efter ordinarie arbetstid är förbjudet utan arbetsgivarens medgivande. |
| **Allmänt för allas trevnad** | Vi vårdar vårt språk, passar tiderna, hälsar när vi kommer och går, är lojala mot företaget. Ett vänligt ord, ett glatt hej, en hjälpsam hand är enkla medel för att skapa trivsel. Obehöriga skall avvisas från arbetsplatsområdet. |

## Viktigt att visa den nyanställda

- Brandsläckare, brandfilt, nödutgångar och uppsamlingsplats
- Första hjälpen-utrustning, ögondusch och hur den används
- Vem man vänder sig till i arbetsmiljöfrågor
- Risker i arbetet (t.ex. belastningsskador) och skyddsutrustning
- Telefon och andra kommunikationsmedel
