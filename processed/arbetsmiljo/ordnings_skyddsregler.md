# Gemensamma ordnings- och skyddsregler

**Projekt:** {{projekt}} · **Plats:** {{plats}}  
Gäller alla som vistas på arbetsplatsen.

Reglerna är projektanpassade minimikrav. Företagets egna regler kan vara strängare.

| Område | Regel på denna arbetsplats |
|--------|----------------------------|
| Skyddsutrustning | Skyddsskor med tåhätta och spiktrampskydd. Hjälm och varsel enligt skyltning och riskbedömning. Övrig PPE enligt moment. |
| Ordning | Var och en städar efter sitt arbete. Material på anvisad plats. Transportvägar öppna. |
| Skyddsanordning | Får inte tas bort utan ersättningsskydd och medgivande. Återställ alltid. |
| Heta arbeten | Tillstånd krävs. Behörighet, släckare och efterbevakning enligt tillstånd. |
| Tillfällig el | Endast behörig gör ingrepp. Jordfelsbrytare. Kablar skyddas. |
| Buller och damm | Välj tystare / dammsnål metod när det går. Använd anvisat skydd. |
| Kemikalier | Anmäls till arbetsledning. Följ SDB. Inga okända ämnen på plats. |
| Maskiner | Uppställning på anvisad plats. Besiktningspliktig utrustning får användas först efter kontroll av intyg. |
| Tillbud och skada | Informera närmaste chef omedelbart. Chef meddelar BAS-U. Skyddsombud kallas. |
| Rökning | Endast anvisad plats utomhus. |
| Alkohol och droger | Noll påverkan under arbetstid. Varningsklassad medicin anmäls om den påverkar säkerheten. |
| Kränkande behandling | Accepteras inte. Rapporteras till chef / skyddsombud. |
| Mobil och foto | Arbetsanvändning. Foto av personer eller skyddsbrister enligt projektets regel. |
| Obehöriga | Avvisas vänligt men bestämt. Alla hjälps åt att bevaka tillträde. |
| Arbetstid | Enligt anslag och avtal. Avvikelse som påverkar samordning meddelas BAS-U. |
| Byggmöte | Arbetsmiljö är stående punkt. Avvikelser från ronden tas upp. |
